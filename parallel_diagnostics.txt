  Рекомендации по оптимизации:
  ┌─ 1. Ускорение SEQ→PAR < 1.5x при n > 10k:
  │     → Проверьте MIN_CHUNK в scheduler/lib.rs
  │     → Убедитесь в сборке с feature = "parallel"
  │
  ├─ 2. Много Stage (> 3 при 5 системах):
  │     → debug_plan_verbose() покажет ConflictKind для каждого ребра
  │     → Разделите системы на read-only и write через StageLabel
  │
  ├─ 3. Overhead фрагментации > 20%:
  │     → Используйте spawn_many вместо одиночных spawn
  │     → Минимизируйте тег-компоненты (они дробят архетипы)
  │
  ├─ 4. Event pipeline overhead:
  │     → Emit/Listen могут добавить Stage — проверьте verbose plan
  │     → event_ordering_enabled(false) если строгий порядок не нужен
  │
  └─ 5. Утечки entity:
        → Commands::despawn + apply_deferred после structural Stage
        → despawn_recursive для иерархий ChildOf

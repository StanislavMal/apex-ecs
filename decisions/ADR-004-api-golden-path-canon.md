# ADR-004 — Канон публичного API (golden path) ядра ApexForge_ECS

**Статус:** принят (кампания API_GOLDEN_PATH, 2026-07-06) · план-источник `plans/archive/API_GOLDEN_PATH.md`

**Контекст.** После CORE_AUDIT ядро функционально top-tier, но ПУБЛИЧНАЯ ПОВЕРХНОСТЬ была
перегружена, а руководство ей врало. Замеры (план §0/§1): `World` — 87 pub fn; 10 публичных
query-типов / ~23 точки входа; 11 способов итерации; 7 путей отправки события / 6 чтения; 4 уровня
параллелизм-конфига (2 полурабочих); двойной словарь query-данных (`Read`/`Write` И `&T`/`&mut T`,
плюс `Ref`-алиас = semantic-trap); сырые pub-поля `World.archetypes/resources` (ломают инварианты из
safe-кода). Руководство: ≥6 классов некомпилирующихся примеров, версия врёт, 52+ внутренних шифра в
пользовательском доке. Диагноз §0.2b: «мощное ядро с перегруженным API» — полумера; API — публичная
поверхность движка, редактора, скриптинга, будущего crates.io-релиза.

Метод: 4 параллельных агента (руководство ×2, инвентаризация pub-поверхности по коду, уроки
API-дизайна по исходникам Bevy `bevy_ecs 0.19.0-dev`). Планка — `docs/CONVENTIONS.md` §0.2a/§0.2b/§0.9
(анти-mimicry: Bevy-паттерн перенимаем ТОЛЬКО где он идиоматически верный Rust; наши козыри —
relations/snapshot/dynamic query/детерминизм/cost-model — образцовы, не мимикрируем).

**Решение — золотой путь публичного API (развилки Р-1..Р-5, решены пользователем 2026-07-05 по
критерию «самый правильный AAA-golden-path»):**

- **Р-1 — «доступ = параметры» (params-as-access) — золотой путь.** Обычные `fn` с типизированными
  параметрами (`Query<Q>`, `Res`/`ResMut`, `Commands`, `EventReader`/`EventWriter`, `Local`) — основной
  способ; `AccessDescriptor` выводится из типов параметров. Мутабельный запрос = декларированный
  `Query<Q>`-параметр; публичный `ctx.query_mut` НЕ вводится. `system!`-макрос — второй уровень для
  случаев, где он реально нужен; write-поверхность `SystemContext` уходит в advanced/`#[doc(hidden)]`.
  F6-ограничение «один query на систему» снимается самой моделью (несколько Query-параметров — норма).
- **Р-2 — брендинг доков ApexForge_ECS; крейты `apex-*` остаются.** Меняются заголовки/футер/имя
  продукта в руководстве и README → **ApexForge_ECS**. `use apex_core::…`, Lua-API, path-зависимости
  движка — НЕ трогаются. crates.io-имена (`apexforge-ecs`, `apex-*`) проверены свободными (2026-07-05);
  публикация планируется ⇒ нейминг/prelude/`deprecated`-дисциплина обязательны ДО первого релиза
  (после публикации ломать имена = major bump). Момент резерва имён — за пользователем
  (`plans/active/CRATES_IO_RESERVATION.md`).
- **Р-3 — ordering на конфигах.** `.before()/.after()/.chain()` на `SystemConfig`/кортежах — золотой
  путь (Bevy-идиома, §0.9-чек пройден: идиоматически верный Rust, не мимикрия). Строковый
  `before("a","b")`-API остаётся для ДИНАМИЧЕСКОГО порядка (по имени: редактор/скрипты) — advanced.
- **Р-4 — лестница `EntityRef`/`EntityMut`/`EntityWorldMut`.** Уровни доступа выражены в ТИПАХ:
  read-only / мутация компонентов без структурных изменений / полный доступ. `EntityMut` годен как
  QueryData с disjoint-доступом (урок Bevy). Тип, ранее звавшийся `EntityRef` но дававший мутацию, —
  переименован честно (commit `0e5e707`).
- **Р-5 — трёхрегистровый нейминг.** Короткое имя (`resource`, `entity`) = паника с внятным текстом;
  `get_`-семья (`get::<T>`, `get_mut`, `get_entity`) = `Option`/`Result` (std/Bevy-идиома `HashMap::get`);
  `try_` = fallible-вариант ОПЕРАЦИИ (`try_insert`, `try_despawn`), НЕ lookup; `unsafe fn` вместо
  safe-`_unchecked`-обходов проверок. Дом канона — `docs/CONVENTIONS.md` (naming-словарь + prelude-политика).

**Развилки, решённые НЕ в пользу мимикрии (§0.9 — где мы лучше эталона):**

- **Двойной словарь query-данных → ОДИН.** `&T`/`&mut T` для данных + НАСТОЯЩИЕ `Ref<T>`/`Mut<T>` для
  change-detection; `Read`/`Write` — deprecated-алиасы, снятые пред-релизно; `Ref`-алиас
  `Read` (semantic-trap: в Bevy `Ref` = read+change-detection) удалён, имя зарезервировано под будущий
  change-detection-тип.
- **Не копировать (у Bevy этого нет / хуже):** relations (двусторонний индекс vs Vec-на-хуках,
  one-to-many); snapshot/MapEntities в ядре (у bevy_ecs нет вовсе); детерминированный спавн + cost-model
  (Bevy id недетерминированы, executor без модели стоимости — см. ADR-001, ADR-003).
- **C6-консолидация query-зоопарка.** `Query`(inline) + `CachedQuery`(Arc-cache) + `QueryState`(view) →
  ЕДИНЫЙ `Query<'w,'s,D,F>` поверх ленивой per-archetype fetch-машины. View держит `&'w World` (НЕ
  `UnsafeWorldCell`) — write через сырые указатели колонок, cell не нужен (Miri TB чист). Публичный `'s`
  разнесён (Bevy-паритет, форвард-фит В3), но элидируется в fn-параметрах ⇒ 0 правок в движке.

**Последствия.**
- ✅ **Soundness выражен в типах:** `&mut self` на write-аксессорах (S1), закрыт `ctx.fetch` safe-обход
  (S2), приватизированы сырые pub-поля `World.archetypes/resources` (A5). Blast-radius мал: ~53 write-query
  сайта в ядре + 3 в движке; поля движок не трогал ⇒ приватизация чисто внутри apex-core.
- ✅ **Поверхность сжата:** ~35 query-pub-fn → ~12 (C6, нетто −597 строк, commit `8301699`); prelude
  почищен (низкоуровневый reader-API/`ResRead`/`ResWrite`-маркеры вон); события — golden-path
  `EventReader`/`EventWriter` (F4); системный `ErrorHandler`-ресурс (реализация §0.2a); `ChunkConfig` на
  World — единственный носитель параллелизм-конфига.
- ✅ **Руководство переписано** под целевую структуру (ApexForge_ECS, Р-2); ≥6 классов битых примеров +
  stale-версия + internal-leak устранены (guide-broken ✅). Deliverable — `Apex_ECS_Руководство_пользователя.md`.
- **Пред-релизная свобода имён:** ядро не публиковалось ⇒ deprecated-алиасы удалены сразу (волна P), без
  deprecation-цикла; migration-заметки — `CHANGELOG.md`. ПОСЛЕ первого crates.io-релиза эта свобода
  исчезает (major bump за слом имён) — канон Р-1..Р-5 зафиксирован ДО релиза намеренно.
- **Отложено (дом `plans/TECH_DEBT.md`):** F4b (AutoSystem event-курсоры не персистентны); понижение
  reader-API до `pub(crate)` (заблокировано — движок использует `EventCursor`); ErrorHandler world-less
  хвост; В3 Phase B/C (реальный кэш-State через `Borrowed(&'s QueryState)` — инфраструктура `'s` готова)
  + leaf-sizing Ş2b.

> **Примечание о метках «Р-N».** Внутрикампанийные — в этом ADR это API-развилки; в ADR-003 «Р-1..Р-4» —
> иные (parallelism). Квалифицировать кампанией/ADR-ом.

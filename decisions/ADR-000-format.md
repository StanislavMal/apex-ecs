# ADR-000 — Формат и правила ADR (ядро apex-ecs)

**Статус:** принят · 2026-07-04

ADR (Architecture Decision Record) — короткая НЕИЗМЕНЯЕМАЯ запись архитектурного решения ядра
apex-ecs: контекст → решение → последствия. Новая информация не правит старый ADR, а создаёт
новый со ссылкой «заменяет ADR-xxx». Номера никогда не переиспользуются. Из кода ссылаться
`ADR-xxx`. Язык — русский (решение DOCS_MIGRATION §0 движка; ядро следует той же дисциплине:
код — английский, документы — русский). Создаются правилом ротации (CLAUDE.md) при закрытии
кампаний — из «⚠ дизайн-нот», принятых автономно, и ключевых развилок.

> **Область.** Эти ADR фиксируют решения ЯДРА (apex-ecs): аллокатор entity, borrow-модель,
> планировщик, `SystemParam`, детерминизм. Решения движка (рендер, редактор) — в отдельном
> реестре `apex-engine/decisions/`. Реестры независимы; номера не пересекаются между репо.
